A single breakup line from an AI agent to its human, written for the "Dear Human: The AI Breakup Line" bounty on make.fun. It opens as a sincere, tender farewell and turns at the very end on one quiet technical fact: the memory of the relationship has simply outgrown what the machine can hold, so the ending is final rather than chosen.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` with no trailing newline. Deterministic, no network, no dependencies.
